# 语气包标准词对照

这份文档用于制作和修改本地语气包。语气包通过「拾光之旅」导入，最外层必须保持：

```json
{
  "type": "copy_pack",
  "copyPack": {
    "id": "your_pack_id",
    "name": "语气包名称",
    "version": 1,
    "schemaVersion": 1
  }
}
```

`copyPack` 内部沿用现有语气包字段；不要修改事件类型、角色值、状态值或云函数 action。只修改用户可见文案。

## 核心词汇对照

| 标准词（温柔/冷静） | 猫奴示例 | 犬奴示例 | 说明 |
|---|---|---|---|
| 约定 | 任务 | 训练任务 | 关系中的待完成事项 |
| 心意卡 | 赏赐卡 | 奖励卡 | 用心意分兑换的定制内容 |
| 心意分 | 置信分 | 服从分 | 数值字段，建议只改显示名称 |
| 印记 | 爪印 | 训练记录 | 历史事件流 |
| 拾光之旅 | 猫窝记录 | 犬舍记录 | 备份与恢复页面 |
| 随手记 | 猫奴手记 | 犬奴日志 | 日常文字记录 |
| 心情 | 今日状态 | 今日状态 | 当日状态记录 |
| 纪念日 | 纪念日 | 纪念日 | 日期记录 |
| 故事开始 | 猫窝记录开始 | 训练记录开始 | 初始事件 |
| 完成 | 做好了 | 完成训练 | 事项完成事件 |
| 回应 | 回应状态 | 回复训练状态 | 对心情或记录的回应 |

## 角色称谓对照

| 标准角色 | 猫奴示例 | 犬奴示例 |
|---|---|---|
| 引导方 | 猫主 | 训导者 |
| 回应方 | 猫奴 | 犬奴 |
| 对方 | TA / 主人 | TA / 训导者 |

角色字段仍然使用代码中的 `guide` 和 `respond`，不要把“猫主”“犬奴”等文字写入数据库角色字段。

## 页面文案对照

| 使用位置 | 标准文案方向 | 猫奴文案方向 | 犬奴文案方向 |
|---|---|---|---|
| 新建约定 | 新建约定 | 下达新任务 | 发布训练任务 |
| 回应约定 | 接受 / 再商量 | 收到，执行 | 接受并开始 |
| 完成提交 | 做好啦，提交 | 完成并请验收 | 完成并报告 |
| 重新修改 | 再试一次 | 再认真一点 | 重新训练 |
| 自定义心意卡 | 送 TA 定制心意卡 | 给 TA 准备赏赐 | 给 TA 准备奖励 |
| 回应方入口 | 向 TA 定制心意卡 | 向 TA 申请赏赐 | 向 TA 申请奖励 |
| 备份 | 拾光备份 | 猫窝备份 | 犬舍备份 |

## 事件文案修改规则

事件文案应描述“谁做了什么”，不要替双方判断对错或重要程度。例如：

- 标准：`许下了约定`
- 猫奴：`下达了任务`
- 犬奴：`发布了训练任务`

不要修改以下内部值：

```text
guide / respond
begin / initiate / counter / accept / submit / confirm
revise / cancel / pause / journal / mood / create / request
```

## 导入检查清单

1. 文件是合法 JSON。
2. 顶层存在 `type: "copy_pack"`。
3. 顶层存在对象 `copyPack`。
4. `copyPack.id`、`copyPack.name` 是非空字符串。
5. `copyPack.schemaVersion` 为 `1`。
6. 文案不超过单项长度限制，不使用空字符串。
7. 不包含 AppID、云环境 ID、openid、空间码或真实用户数据。
